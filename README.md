## What it does

`main.py` writes one original funny line to `/output/entry.txt`:

> My phone's battery dies at 2% like it's making a dramatic exit, then turns back on just long enough to show me the low-battery warning again.

The line is written by hand for this bounty. Everybody recognises the
everyday truth (a phone that dies at 2% and then switches itself back
on), the ending lands a surprise that still makes sense (it comes back
only to show the low-battery warning again), and nothing in it explains
the joke.

## Run

```sh
python3 main.py   # writes /output/entry.txt (or $OUTPUT_DIR/entry.txt)
```

Deterministic: the same line on every run. The output is 141
characters of UTF-8 text (141 bytes, plain ASCII), within the 1–200
character gate, a single sentence on a single line.
